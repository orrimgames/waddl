# waddl.

Tiny robots with big feelings. A robotics studio under the orrimgames umbrella.

- **Site**: https://orrimgames.github.io/waddl/
- **Pip**: our first robot, a duckling companion. ~$45 BOM, 4 servos, ESP32 brain.
- `index.html` brand page / `robot.html` Pip concept / `sim.html` Three.js sim / `bom.html` prototype plan
- `cad/pip_v03.scad` printable parametric OpenSCAD (shell, rocker feet, wings, hinged beak); `cad/build_model.py` builds `assets/pip.glb` for the sim
- `firmware/pip_gait_v02.ino` eased waddle gait + OLED face + touch + idle sleep
- `docs/PRINTING.md` print & assembly guide
- `assets/renders/` turntable renders of the v0.1 concept

No hardware has been purchased. bom.html is the approval document.
